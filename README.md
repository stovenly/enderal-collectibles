# Enderal Collectibles Tracker

**<https://stovenly.github.io/enderal-collectibles/>**

Drop an Enderal save (`.ess`) on the page and get back what you still have to
collect, as a list and as pins on the world map:

- Magic Symbols
- Mystical Symbols
- Phasmalist Souls
- Vatyra Fragments
- Ice Claws

Saves from both Enderal (Classic) and Enderal Special Edition work, with
Forgotten Stories. Assumes an otherwise unmodded game. Mods that move or remove
collectibles will throw the results off.
